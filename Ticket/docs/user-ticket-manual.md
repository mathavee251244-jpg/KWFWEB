# คู่มือการใช้งานระบบ IT Helpdesk — สำหรับผู้ใช้งานทั่วไป

## 1. การเข้าสู่ระบบ (Login)

1. เปิดเบราว์เซอร์และไปที่ URL ของระบบ IT Helpdesk ที่ฝ่าย IT แจ้งให้
2. กรอก **Username** (เช่น `fern`, `hr`, `acc006`) และ **Password**
3. กด **เข้าสู่ระบบ**
4. หน้าจอหลักแบบ Windows Desktop จะปรากฏขึ้น

---

## 2. การแจ้งปัญหา IT (Submit Ticket)

### วิธีแจ้งปัญหา

1. กดปุ่ม **"แจ้งปัญหา IT"** บนหน้าแรก หรือคลิกไอคอน **Ticket** บน Taskbar
2. **เลือกประเภทปัญหา** จากปุ่ม Quick Fill (อินเทอร์เน็ต, เครื่องพิมพ์, อีเมล, รหัสผ่าน, คอมพิวเตอร์, อื่นๆ) ระบบจะกรอกข้อมูลเบื้องต้นให้อัตโนมัติ
3. ตรวจสอบและแก้ไข **ข้อมูลผู้แจ้ง** (ชื่อ, แผนก, อีเมล — ระบบกรอกอัตโนมัติจากบัญชีที่ login)
4. กรอก **หัวข้อปัญหา** ให้กระชับและชัดเจน
5. กรอก **รายละเอียดปัญหา** ให้ละเอียดที่สุด:
   - ปัญหาเริ่มเกิดเมื่อไหร่
   - อาการที่พบ
   - ลองแก้ไขอะไรไปแล้ว
6. **แนบไฟล์** ถ้ามี (ภาพหน้าจอ, log file, เอกสาร)
7. เลือก **ระดับความสำคัญ** ให้เหมาะสม
8. กด **"ส่ง Ticket"**
9. ระบบจะแสดง **หมายเลข Ticket** (เช่น TKT-021) เก็บเอาไว้สำหรับติดตาม

### การแนบไฟล์

- รองรับไฟล์: PNG, JPG, PDF, DOCX, XLSX, TXT, ZIP
- ขนาดสูงสุด: 10MB ต่อไฟล์
- วิธีแนบ: คลิกที่กล่องหรือลาก-วางไฟล์

---

## 3. การติดตามสถานะ Ticket

1. กดไอคอน **"Ticket ของฉัน"** บน Taskbar หรือหน้าแรก
2. จะเห็นรายการ Ticket ทั้งหมดที่แจ้งไว้
3. กด Ticket ที่ต้องการเพื่อดูรายละเอียด

---

## 4. ความหมายของสถานะ Ticket

| สถานะ | ความหมาย |
|-------|----------|
| **ใหม่** (New) | ระบบรับปัญหาแล้ว รอ IT รับงาน |
| **มอบหมาย** (Assigned) | IT รับงานแล้ว รอดำเนินการ |
| **กำลังดำเนินการ** (In Progress) | IT กำลังแก้ไขปัญหา |
| **รอผู้ใช้** (Waiting User) | IT ต้องการข้อมูลเพิ่มเติมจากคุณ |
| **แก้ไขแล้ว** (Resolved) | IT แก้ไขเสร็จแล้ว กรุณายืนยัน |
| **ปิด** (Closed) | Ticket ปิดแล้ว |
| **เปิดใหม่** (Reopened) | ปัญหาเกิดขึ้นอีก |

---

## 5. ระดับความสำคัญ (Priority) และ SLA

| ระดับ | ใช้เมื่อ | เวลาตอบสนอง (SLA) |
|-------|---------|-------------------|
| **วิกฤต** (Critical) | ระบบหลักดับ, Security breach, กระทบงานทั้งองค์กร | 2 ชั่วโมง |
| **สูง** (High) | ระบบสำคัญใช้ไม่ได้, กระทบงานแผนก, อินเทอร์เน็ตดับ | 8 ชั่วโมง |
| **กลาง** (Medium) | Software มีปัญหา, อีเมลมีปัญหา, เครื่องพิมพ์เสีย | 24 ชั่วโมง |
| **ต่ำ** (Low) | ขอติดตั้งโปรแกรม, ปรับแต่งค่า, ไม่เร่งด่วน | 72 ชั่วโมง |

---

## 6. การตอบกลับ IT (Comment)

1. เปิด Ticket ที่ต้องการตอบกลับ
2. เลื่อนลงไปที่ **กล่อง Comment**
3. พิมพ์ข้อความและกด **"ส่ง"**
4. IT จะเห็น Comment ของคุณและตอบกลับ

> **หมายเหตุ:** ถ้า IT ตั้งสถานะเป็น "รอผู้ใช้" หมายความว่า IT ต้องการข้อมูลเพิ่มเติม กรุณาตอบกลับโดยเร็ว

---

## 7. คำถามที่พบบ่อย

**ถาม: ส่ง Ticket แล้วต้องรอนานแค่ไหน?**
ตอบ: ขึ้นอยู่กับระดับความสำคัญ (ดูตาราง SLA ด้านบน)

**ถาม: ลืมหมายเลข Ticket?**
ตอบ: ไปที่เมนู "Ticket ของฉัน" จะเห็น Ticket ทั้งหมด

**ถาม: แก้ไขปัญหาแล้วแต่ยังมีปัญหาอยู่ทำอยู่ไง?**
ตอบ: เปิด Ticket เดิมแล้วแจ้งใน Comment ว่ายังมีปัญหา IT จะ Reopen ให้

**ถาม: ติดต่อ IT ฉุกเฉินได้ที่ไหน?**
ตอบ: โทรภายใน IT: ext. 1001 หรือ email: it@bangkokseafood.co.th
